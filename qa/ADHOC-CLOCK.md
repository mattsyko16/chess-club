# Standalone ad hoc chess clock — 8 November 2026

Open ../clock.html, or https://mattsyko16.github.io/chess-club/clock.html.

A self-contained HTML clock with optional names, per-player game time and increments, maximum time per move, optional shared game limit, pause/resume, reset confirmation and opposite-facing full-screen panels. No club access or backend is used. It does not record results. Settings use the separate adhoc-clock-settings-v1 local browser key where storage is available.

The Download button exports a self-contained HTML copy. Opening local HTML on a phone depends on the browser and file app. The web URL is the easiest phone option. Closing/reloading loses an unfinished clock; keep the page open and device unlocked.
